# TFG-Laminadora
Código para el desarrollo e integración de una etapa de refrigeración activa en una laminadora de módulos fotovoltaicos mediante PLC Siemens S7-1200, TIA Portal y HMI

Este repositorio contiene los programas, configuraciones y documentación desarrollados durante el Trabajo de Fin de Grado.

##Contenido

Programa de control original contenido en la laminadora (Código_Laminadora_Original) .

Programa de control modificado, con la etapa de refrigeración implementada (Código_Modificado_Con_Refrigeración)


En este repositorio se incluyen los archivos de proyecto .zap16 correspondientes al programa del PLC, tanto la versión original del sistema como la versión modificada desarrollada durante el proyecto. Estos archivos permiten recuperar el proyecto completo y acceder posteriormente al código mediante TIA Portal V16
